# Kanban Board — Командная канбан-доска

Простая, современная и легкая в администрировании Kanban-доска для небольшой команды из 5–6 пользователей. Спроектирована специально для надежного запуска на локальном офисном ПК (включая устаревшие системы) и работы в локальной сети офиса без облачной зависимости или сложных сборок.

---

## 🚀 Быстрый запуск

Для запуска приложения на офисном ПК требуется только установленный **Python 3.11+**.

Предусмотрен автоматический запуск одной командой через npm-скрипт (если установлен Node), либо напрямую через терминал Python:

### Вариант 1: Запуск одной командой (через Python)
1. Откройте терминал в папке проекта.
2. Установите зависимости одной командой:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите сервер:
   ```bash
   python app.py
   ```
4. Откройте браузер по адресу: `http://localhost:3000` (чтобы дать доступ коллегам в вашей офисной сети, используйте IP-адрес этого ПК, например: `http://192.168.1.10:3000`).

---

## 🛠️ Особенности архитектуры

### Backend
* **Python 3.11+** и **FastAPI** — высокопроизводительный, легковесный веб-интерфейс.
* **SQLAlchemy & SQLite** — база данных создается автоматически в виде единого файла `database.db` в корне при первом запуске. Не требует настройки СУБД (PostgreSQL/MySQL).

### Frontend
* **Jinja2** — серверные HTML5 шаблоны для мгновенного рендеринга.
* **Tailwind CSS** — отзывчивая верстка, адаптированная под мобильные экраны и планшеты.
* **SortableJS** — плавная drag-and-drop перестановка карточек задач между колонками и этапами с мгновенным сохранением в БД без перезагрузок.

## 📋 Основной функционал

1. **Канбан-доска**:
   * Разделена на ключевые разделы: **Новая**, **В работе** (с гибко настраиваемыми подэтапами) и **Завершено**.
   * Интерактивный Drag & Drop задач с изменением статуса.
2. **Динамические подэтапы в работе**:
   * В админ-панели вы можете создавать, ранжировать (с помощью индекса сортировки), переименовывать подэтапы.
   * Можно задать **Исполнителя по умолчанию** для каждого подэтапа. При перетаскивании задачи на этот этап она автоматически назначится на ответственного коллегу!
3. **Комментарии**:
   * Каждая карточка поддерживает обсуждение. Комментарии выводятся в истории задачи с указанием автора и времени.
4. **История изменений**:
   * Любые действия (создание, перенос, смена дедлайна, исполнителя или добавление комментариев) автоматически фиксируются в логе истории карточки.
5. **Фильтрация и Поиск**:
   * На главной странице доступен сквозной поиск по названию/описанию задач.
   * Фильтры по Исполнителю, Приоритету и Сортировка по дате или дедлайнам.

## 💾 Резервное копирование и Экспорт

### 📊 Экспорт в Excel
Кнопка **«Экспорт Excel»** на верхней панели моментально создает `.xlsx` таблицу со всеми активными и закрытыми задачами.
Экспортируется детальная таблица с полями: `ID`, `Название`, `Описание`, `Автор`, `Исполнитель`, `Дата создания`, `Срок`, `Статус`, `Этап в работе` и `Дата завершения`. Форматируется с закрепом шапок и автоподбором ширины ячеек.

### 🗄️ Авто-бэкапы базы данных SQLite
Все настройки резервного копирования задаются в файле конфигурации `config.py` или системной среде `.env`:
* **Период проверки**: `daily` (Ежедневно), `weekly` (Еженедельно), `monthly` (Ежемесячно).
* Бэкап проверяется автоматически при входе на доску. Если пришел срок, старая база SQLite физически копируется в папку `backups/` с меткой времени.
* В **Админ-панели** можно:
  * Получить перечень всех файлов бэкапов с их размером.
  * Ткнуть кнопку «Создать бэкап сейчас» для мгновенной копии.
  * **Скачать** любой файл резервной копии прямо на свой ПК через браузер.
### 🧪 Тестирование

Запустить его можно из корня проекта:
