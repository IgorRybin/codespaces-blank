# Kanban Board — командная канбан-доска

**Kanban Board** — это лёгкое и понятное приложение для управления задачами малой команды. Основная идея: минимальная зависимость, быстрый запуск, удобное управление задачами и пользователями через браузер.

---

## 🚀 Быстрый запуск

### 1. Подготовка среды
На локальном компьютере потребуется Python 3.11+.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 2. Запуск сервера

#### Вариант A: нативный Python
```bash
python app.py
```

#### Вариант B: через npm-скрипт
```bash
npm run dev
```

- `python app.py` запускает FastAPI на `http://localhost:8000`
- `npm run dev` запускает через `start.js` и отдаёт приложение на `http://localhost:3000`

### 3. Доступ
Откройте браузер по адресу:

- `http://localhost:8000` или
- `http://localhost:3000`

Чтобы дать доступ коллегам из офиса, используйте IP машины вместо `localhost`, например `http://192.168.1.10:8000`.

## 🧱 Архитектура проекта

Основные части:

- `app.py` — точка входа, запуск FastAPI, регистрация маршрутов и сидирование.
- `database.py` — подключение SQLAlchemy и фабрика сессий.
- `models/models.py` — ORM-модели: `User`, `Task`, `SubStage`, `Comment`, `TaskHistory`.
- `routers/` — HTTP-маршруты:
  - `auth.py` — логин/логаут и сессии;
  - `board.py` — основной интерфейс канбан-доски;
  - `tasks.py` — работа с задачами;
  - `admin.py` — админ-панель.
- `templates/` — Jinja2-шаблоны для UI.
- `static/` — статические файлы и CSS.
- `backups/` — папка для резервных копий SQLite.
- `exports/` — экспортированные Excel-файлы.

## ⚙️ Конфигурация

Основные настройки лежат в `config.py`.

```python
DATABASE_URL = "sqlite:///database.db"
SESSION_COOKIE_NAME = "kanban_session"
BACKUP_ENABLED = True
BACKUP_INTERVAL = "daily"
BACKUP_FOLDER = "backups"
```

Можно добавить `.env` рядом с проектом и задать свои значения.

## 🛠️ Поддержка и изменения

Для поддержки и внесения изменений используйте следующие шаги:

1. **Обновите документацию** — `README.md` и файлы в `docs/`.
2. **Проверяйте структуру** — список файлов и назначение модулей.
3. **Тестируйте изменения** — `python -m unittest discover tests`.
4. **Соблюдайте семантику коммитов**:
   - `fix:` — багфикс;
   - `feat:` — новая функциональность;
   - `docs:` — документация;
   - `refactor:` — чистка кода.

Подробнее по процессу поддержки — `docs/MAINTENANCE.md`.
